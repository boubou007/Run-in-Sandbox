# SEO : recherche, architecture, contenu et technique

## Quand utiliser cette Skill
- Construire ou refondre une stratégie de trafic organique.
- Choisir les mots-clés et l'architecture d'un site.
- Auditer un site qui ne se positionne pas.

## Quand ne PAS l'utiliser
- Rédiger la page de vente elle-même → copywriting-pro.
- Performance pure et Core Web Vitals hors SEO → web-design-pro.

## Procédure
1. **Recherche de mots-clés** : partir des problèmes du client, pas du vocabulaire interne.
   Collecter la requête, le volume, la difficulté, l'intention et la valeur commerciale.
2. **Qualifier l'intention** : informationnelle, navigationnelle, comparative, transactionnelle.
   Une page qui se trompe d'intention ne se positionne pas, quel que soit son contenu.
3. **Analyser les résultats existants** : type de page qui se positionne, profondeur attendue,
   format dominant, sections communes. C'est le cahier des charges implicite.
4. **Prioriser** : viser d'abord les requêtes où l'autorité actuelle permet de gagner
   (longue traîne, faible difficulté, intention commerciale claire).
5. **Architecture** : une page = une intention. Regrouper en piliers et articles satellites,
   maillage interne descendant et transversal, URL courtes et stables.
   Traiter la cannibalisation : deux pages sur la même intention se nuisent.
6. **On-page** : title unique et porteur de la requête, meta description orientée clic,
   un seul H1, hiérarchie H2/H3 logique, réponse utile dans les 100 premiers mots,
   attributs alt descriptifs, liens internes contextuels.
7. **Technique** : indexabilité (robots.txt, balise noindex, canonique), sitemap,
   codes de statut, redirections, rendu JavaScript, vitesse et Core Web Vitals,
   ergonomie mobile, HTTPS, données structurées schema.org, hreflang si multilingue.
8. **Audit** : vérifier indexation, positions, pages orphelines, contenu dupliqué,
   liens cassés, profondeur de clic.
9. **Mesure** : impressions, clics, position moyenne, taux de clic, conversions organiques.

## Contrôles qualité
- [ ] Chaque page cible une intention unique.
- [ ] Les volumes et difficultés sont sourcés, non inventés.
- [ ] La cannibalisation a été vérifiée.
- [ ] Les points techniques bloquant l'indexation sont traités en priorité absolue.
- [ ] Le contenu répond mieux que les résultats existants, pas seulement plus longuement.

## Critères de fin
- Liste de mots-clés priorisée, architecture définie, plan de contenu daté.
- Points techniques bloquants identifiés et hiérarchisés par impact.

## Format de livrable
Tableau mots-clés (requête, volume, difficulté, intention, page cible) ·
Arborescence et maillage · Plan de contenu · Liste d'actions techniques par priorité ·
Indicateurs de suivi.
