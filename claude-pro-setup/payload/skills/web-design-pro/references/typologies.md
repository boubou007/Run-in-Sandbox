# Typologies de sites — web-design-pro

Référence chargée à la demande. Spécificités par type de projet.

## Landing page
- **Objectif** : une seule conversion.
- **Structure** : promesse → problème → solution → bénéfices → preuves → offre →
  objections → réduction de risque → action finale.
- **Pièges** : appels à l'action concurrents, rupture de promesse avec la source de
  trafic, témoignages vagues, formulaire trop long.
- **Priorité** : premier écran et vitesse d'affichage.
- Voir aussi la Skill `landing-page-conversion`.

## Site SaaS
- **Objectif** : essai gratuit, démonstration ou inscription.
- **Pages clés** : accueil, fonctionnalités, tarifs, cas d'usage, documentation,
  connexion, blog.
- **Tarifs** : trois paliers, un mis en avant, comparaison lisible, réponse claire
  à « que se passe-t-il si je dépasse ». La page tarifs est la plus visitée avant décision.
- **Preuves** : logos clients, chiffres d'usage, sécurité et conformité, disponibilité.
- **Pièges** : jargon interne, fonctionnalités listées sans bénéfice, tarifs opaques.

## Dashboard / application interne
- **Objectif** : efficacité d'usage, pas séduction.
- **Priorités** : densité d'information maîtrisée, hiérarchie claire, filtres et
  recherche, actions groupées, raccourcis clavier, états de chargement partiels.
- **Tableaux** : colonnes triables, largeurs stables, pagination ou défilement virtuel,
  colonne d'actions à droite, en-tête figé.
- **Pièges** : animations décoratives qui ralentissent un usage répété, graphiques
  décoratifs sans lecture possible, états vides non conçus.
- **Règle** : ce qui est utilisé cent fois par jour doit être atteignable en un geste.

## E-commerce
- **Objectif** : ajout au panier puis paiement.
- **Fiche produit** : galerie, prix et disponibilité visibles sans défiler, variantes
  claires, livraison et retours annoncés tôt, avis, produits liés.
- **Paiement** : nombre d'étapes minimal, paiement invité possible, coûts totaux
  affichés avant la dernière étape, indicateur de progression, reprise de panier.
- **Pièges** : frais découverts en fin de parcours (première cause d'abandon),
  création de compte imposée, photos de mauvaise qualité.

## Portfolio
- **Objectif** : obtenir un contact qualifié.
- **Structure** : sélection resserrée plutôt qu'exhaustive, études de cas avec
  contexte, rôle exact, décisions et résultat, contact évident.
- **Pièges** : galerie sans contexte, trop de projets, absence de rôle précisé,
  contact caché en bas de page.

## Site vitrine professionnel
- **Objectif** : crédibilité et prise de contact.
- **Structure** : ce que vous faites, pour qui, preuves, méthode, équipe, contact.
- **Priorités** : coordonnées vérifiables, mentions légales, référencement local
  si activité géographique.
- **Pièges** : texte institutionnel creux, photos génériques, absence d'adresse réelle.

## Interface mobile responsive
- **Priorités** : pouce atteignable (actions principales en bas), formulaires avec
  le bon type de clavier (`type="email"`, `inputmode="numeric"`), champs larges,
  navigation accessible d'une main, contenu avant décoration.
- **Pièges** : survol utilisé comme seul moyen d'accès à une information,
  éléments fixes qui masquent le contenu, menus profonds, saisie perdue au retour arrière.
